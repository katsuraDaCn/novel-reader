# 小说阅读器（桌面版）

一个简洁的 Windows 桌面小说阅读器，基于 Electron 构建。专注本地 TXT 阅读，界面清爽，阅读进度自动记忆。

## 运行

需要先安装 [Node.js](https://nodejs.org/)（18 或更高版本），然后在项目目录执行：

```bash
npm install     # 首次运行前安装依赖
npm start       # 启动阅读器
npm run shortcut  # 安装到“开始菜单 → 所有应用”，并尝试自动固定到“开始”屏幕
```

启动入口指向 `node_modules\electron\dist\electron.exe`，应用图标在 `assets/icon.ico`。
Windows 11 禁止脚本直接固定到“开始”屏幕，`npm run shortcut` 只会报告
`PIN_STATE=ALREADY_PINNED` / `PIN_STATE=BLOCKED`，这不影响快捷方式本身：
打开开始菜单 → 所有应用 → 右键「小说阅读器」→ 固定到“开始”屏幕即可（一次点击）。

## 功能

- **书架管理**：导入 TXT 小说（文件对话框或直接拖进窗口）、按最近阅读排序、显示阅读进度、删除书籍；卡片可按住左键拖动调整顺序（拖过一次后固定为自定义顺序，新导入的书排在最后）
- **隐私书架**：右键任意书籍「隐藏此书」，书架右上角 🔒 输入密码才能查看；密码加盐哈希存储（scrypt），连错 5 次锁定 30 秒，重启自动上锁，隐藏书在解锁前对界面完全不可见
- **编码自动识别**：UTF-8 / UTF-8 BOM / UTF-16 LE / UTF-16 BE / GBK / GB18030 全部支持，网上下载的老 TXT 不会乱码
- **章节自动识别**：按"第X章 / 第X节 / 第X卷 / 序章 / 楔子 / 番外"等常见标题自动分章；没有章节标记的长文会自动按约 1.2 万字分节
- **目录与全文搜索**：目录面板可搜索章节标题，也能搜索正文内容，点击结果直接跳转并高亮关键词
- **书签**：阅读时点顶栏 🔖 收藏当前位置（精确到章节内滚动位置），目录面板「书签」标签页可跳转、删除；目录中含书签的章节会标 🔖
- **阅读进度记忆**：精确到章节内的滚动位置，下次打开自动跳回上次读到的地方
- **阅读设置**：字号、行距、页宽、字体（默认/宋体/黑体/楷体）均可调，设置自动保存
- **四套主题**：白天 / 羊皮纸 / 护眼绿 / 夜间
- **快捷键**：`←` `→` 上一章/下一章，`Esc` 关闭面板或返回书架，`F12` 开发者工具

## 数据存储

- 导入的书会复制一份到 `data/books/`（JSON 格式），之后移动或删除原 TXT 不影响阅读
- 书架记录（含阅读进度）保存在 `data/library.json`
- 阅读设置保存在浏览器 localStorage

## 项目结构

```
main.js              Electron 主进程（窗口、文件对话框、导入/存储 IPC）
preload.js           预加载脚本（安全地暴露 API 给界面）
lib/text.js          文本解码 + 章节切分（纯 Node，可独立测试）
renderer/            界面（原生 HTML/CSS/JS，无框架无构建）
test/                编码与章节切分的自动化测试
```

## 测试

```bash
npm run test:text
```

会生成多种编码的样例小说并验证解码、章节识别、自动分节逻辑。
